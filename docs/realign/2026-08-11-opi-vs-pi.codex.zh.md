## 14. 权限与沙箱

**opi：** 工具策略分别定义编程模式和只读模式的默认值，并要求对无界面模式的变更操作显式选择加入（`crates/opi-coding-agent/src/policy.rs:18`, `crates/opi-coding-agent/src/policy.rs:39`, `crates/opi-coding-agent/src/policy.rs:64`）。项目信任依次解析 CLI 覆盖、已注册的 resolver 投票、已存储信任、全局默认值，最后解析 UI；resolver registry 在加载项目资源前封闭，无界面模式下未解析的询问会映射为不信任（`crates/opi-coding-agent/src/project_trust.rs:458`, `crates/opi-coding-agent/src/project_trust.rs:601`, `crates/opi-coding-agent/src/project_trust.rs:648`）。

- 外部 `command.execute` 授权与工具启用相互独立：本地默认允许，外部适配器默认询问，拒绝会对模型隐藏该能力，而无界面模式下没有 broker 的询问会以关闭方式失败（`crates/opi-coding-agent/src/execution/permission.rs:1`, `crates/opi-coding-agent/src/execution/permission.rs:40`, `crates/opi-coding-agent/src/execution/permission.rs:152`）。
