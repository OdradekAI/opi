# Pi 1.0.4 → 1.2.0 升级分析

复核日期：2026-10-16。旧证据为 [1.0.4 原始清单](evidence/pi-1.0.4/source-manifest.json)，新对象为[当前清单](source-manifest.json)；完整机器差异见 [version-delta.json](version-delta.json)。旧源码快照不在工作区，所以本轮可以作路径/摘要比较与当前实现、旧报告、发行说明的语义对照，不能声称做了完整旧新源码逐行 diff。旧正文的精确恢复见[历史说明](evidence/pi-1.0.4/README.md)。

两清单的排除目录、文档后缀、树摘要算法与 `symlink_policy: reject-all-symlinks-and-reparse-points` 一致。比较工具输出中的“缺少该字段的 legacy manifest 不能证明历史链接处理”是通用条件限制，本次两个清单并不缺少该字段。本轮不继承旧版审读为新读，当前记录逐份绑定新摘要。

## 原结论的更正与保留

| 旧基线中的结论/方向 | 当前判断、依据与限制 |
|---|---|
| 实验 client/protocol/server + Session worker 是仍存在的可选主链 | 已被替代/移除。Chord 1.2 的 typed host runtime 替换旧 facet/service；三包不再发布，coding-agent 的旧实验运行栈也被删除。仅保留 source-resolver 的目录名不能证明服务栈存在。[Chord changelog](../../../.repo/pi-1.2.0/packages/chord/CHANGELOG.md#L3) |
| 默认 CLI 的 AgentSession → Agent → Models、SessionManager JSONL 会话树 | 当前仍成立；产品重试/压缩/UI 仍属上层。SDK 显式传入 ModelRuntime streamFn，不能用 compat fallback 推断实际默认请求走全局兼容入口。[SDK](../../../.repo/pi-1.2.0/packages/coding-agent/src/core/sdk.ts#L411) |
| Durable 与 Chord 集成意味着产品默认已迁入持久任务服务 | 无此接线证据。当前真实消费者为自行组装 Harness/SQLite 的 issue triage 脚本；Durable/env 仍有独立库地位。[triage](../../../.repo/pi-1.2.0/scripts/issues/triage.ts#L114) |
| Chord 旧 service/facet/bundler API 与 CBOR Session 协议 | 不能继续沿用旧 API。当前是 contracts/host/handle/JSON links，`./node` 改为 host manager 与 nodeLoader；Context/delta 保持子入口，保留名称不等于整个 runtime 兼容。详见 [chord](packages/chord.md) |
| Codemode 只有单一 Node worker 装配 | 当前新增 portable/Cloudflare 子入口，宿主差异必须分别说明；暴露工具仍由宿主授权。详见 [codemode](packages/codemode.md) |
| Durable 的存储、调度、文件工具方向 | 机制继续演进，InputEntry、storage 子入口与环境抽象应按当前实现读；spec 内局部旧类型约束不能压过后续章节与当前入口。详见 [durable](packages/durable.md) |
| telemetry schema 在 agent-core 的 README 示例可直接调用 | 局部陈旧；当前 exports 已无相关 schema。包主体代码不变不意味着它引用的消费者契约仍有效。详见 [telemetry](packages/telemetry.md) |
| 所有 env 测试路径都缺 daemon 准备 | 须按调用链区分。主 CI 与 publish job 已显式构建 daemon；local-release/release 的普通 TypeScript build 后测试路径仍需检查外部准备。未执行这些路径，不称运行失败。详见 [env](packages/env.md) |
| 旧 tui-plan / durable handoff 是当前作者路线图 | 当前相应文件已不在文档清单；旧摘要和解读可恢复，但不能借文件消失断言方向全部兑现/撤回。新的 Chord tutorial/guide/spec 与 Durable spec 分别核查。[文档审计](documentation-audit.md) |

ai 的 Decisions classifier、images input、strict prefer 单次兼容回退、OpenRouter per-key catalog、模型 tier 计价与部分传输超时修正；产品的 configuration schemas、custom message 的 before_agent_start 与启动 busy；TUI 输入/剪贴板/滚动变化等，均在相应包报告按当前实现与测试预期展开。JSONL v3、context_edit、恢复顺序与 agent_settled 在旧基线已存在，本轮重核而不列为新功能。没有把 release 条目当作本次测量或运行验收。

1.1.0 还引入重要公开类型变化：stream function 必须返回专用 `AssistantMessageEventStream`，手写通用 EventStream 子类不再满足其名义类型；专用流记录 response `durationMs`，Agent 记录 execute 耗时而排除 hooks，未执行工具和后来 fetch 的旧 deferred 结果不补计时。外层转发保留内层测量，不能把该值当作 Models 鉴权/加载/重试的完整墙钟时间。[ai breaking change](../../../.repo/pi-1.2.0/packages/ai/CHANGELOG.md#L17)、[流计时](../../../.repo/pi-1.2.0/packages/ai/src/utils/event-stream.ts#L91)、[Agent 工具计时](../../../.repo/pi-1.2.0/packages/agent/src/agent-loop.ts#L821)。

MCP 的重要变化包括：OAuth flow cancellation、close 复用已取 token，任意 JSON structuredContent，issuer 缺 metadata 时 fail closed，以及请求结算后禁止 OAuth refresh 完成再迟到派发。这里的 send signal 防止新派发，不回滚已发请求，也不取消其他请求共享的 refresh；仅改结果类型或列成普通“取消修复”会漏掉这一时序边界。[MCP 升级说明](packages/mcp.md)、[dispatch guard](../../../.repo/pi-1.2.0/packages/mcp/src/transports/streamable-http.ts#L287)。

包外主要变化为：artifact set/消费者安装与发布共用 tarball 机制，issue triage 的 Durable 消费示例，Nix catalog pin 与发行工作流调整。lockfile 和直接依赖精确版本也有变化；本轮仅检查声明和调用，不假称外部依赖内部实现字节相同。
