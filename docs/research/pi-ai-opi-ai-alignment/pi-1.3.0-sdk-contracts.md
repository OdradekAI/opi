所有行采用以下差异分类：**E**＝保留调用能力和所列可观察合同，Rust 命名/类型不要求与 TS 相同；**L**＝语言表达替代（owned、Result、惰性 Future、typed enum）；**S**＝明确的正确性或资源策略差异；**P**＝平台/包边界替代；**G**＝尚缺实现或验证，不能以差异关闭。E 也仍需证据。目标只限 `opi-ai`；SDK 可提供机制，产品默认装配和 session/工具执行/授权不计 SDK 完成。每行 AIR/V 指向候选及矩阵现有身份，不另建 ID 或进度账本。

### Bedrock 无真实凭据代理与 HTTP/1.1

Pi 在 [adapter](../../../.repo/pi-1.3.0/packages/ai/src/api/bedrock-converse-stream.ts)读取 scoped env 的 SKIP_AUTH，在 Pi 层停止显式 bearer 选择并注入 dummy SigV4；锁定 Node AWS SDK 的 ambient bearer 仍可能覆盖，不能据此称 Pi 已有零 ambient 保证；[HTTP/1.1](../../../.repo/pi-1.3.0/packages/ai/src/api/bedrock-converse-stream.ts)及[loopback test](../../../.repo/pi-1.3.0/packages/ai/test/bedrock-response-headers.test.ts#L47)证明这是实际公开代理动作。Rust 目标用显式 typed `ProxyPlaceholderSigning`、caller 提供非标准 endpoint、冻结 region 和 HTTP/1.1 选择表达；保留固定非秘密 placeholder SigV4，不称无签名 NoAuth 或真实 AWS 身份。零读取 environment/store/profile/process/metadata/bearer 凭据，ambient 的真实 key/token 不混入，普通 AWS endpoint 拒绝此模式；不复制 raw ambient SKIP_AUTH 的隐式权威。这是 **E/L/S；AIR-023/057/066→V-09/49/58**，不是延后能力，不新增通用框架。普通 Models 和 direct adapter 均须经本地代理证明 H1、placeholder Authorization、canary 不泄露、正常 framing/回调/终态与 retry/cancel/drop。

## 10. Rust机制与新增限制的修正

[来源审计](pi-1.2.0-parameter-audit.md)逐项区分Pi/protocol/backend/existing-opi/撤回提案。mutation_barrier保留owned同步cutoff、跨Models按key未知效果与正常关闭价值，不再设置默认wait30s/keys256/总15s/ADC60s；Pi15s仅网络refresh。内部queue64继续背压，大合法event/完整terminal不因虚构byte credit失败。

Custom typed options在兼容Models间可复用，upsert/同type替换不构成stale错误；API identity精确保留。Schema降为需Pi TypeBox corpus的条件候选，未知format/keyword/$schema和引用/regex不能靠blanket拒绝关差异；撤回容量/fuel/cache/jobs/全pattern guard。no implicit schema I/O有Pi来源。

HTTP普通crates.io后端的envelope/parser-storage接受范围仅按RDF-22明示（不等于SSE/body总量cap）；真实公共adapter与普通／feature-union包消费者必须证明正常与边界失败、partial/usage及取消／重试封口。其余继续按具体fetch/SDK/source的redirect/retry/protocol/TLS行为，撤回统一none、ADC0retry/60s/16sends/1MiB/depth4、同origin5-hop/双独立executable gate。保留真实source授权/GOOGLE_EXTERNAL_ACCOUNT_ALLOW_EXECUTABLES、30s与5–120s配置、POST retries及单owner。crypto 的 RSA1024/多素数 RSA 拒绝、无 P-521 KX 及上游集合/顺序按 RDF-23 显式接受；该例外不豁免 roots/WebPKI、JWT alg/claims、mTLS/ALPN、宿主隔离、typed 失败与取消。仅用公开 safe rustls/aws-lc-rs seam，不要求本地 FFI/crypto namespace，仍须 native 来源和普通/feature-union 包验证。未列明的 H1-only/roots/key/WS handshake/compression 缺口仍 OPEN，不以 override 或 typed Unsupported 冒称完成。AIR/V数量不变，全部新运行验收未执行。
