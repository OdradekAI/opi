### P18-AUD-001: Unreadable regrade roots are reported as verified

- Axis: invariants
- Severity: Major
- Conformance effect: blocks
- Requirement IDs: P18-FAL-002, P18-MIG-002, PRIN-004
- Claim: `opi-eval regrade` turns a missing or unreadable `trials` directory into an empty `verified` report and exit 0 instead of rejecting absent required evidence.
- Evidence: `crates/opi-eval/src/regrade.rs:67-106` maps `read_dir` failure to an empty vector and treats no failures as verified; `crates/opi-eval/src/cli/regrade.rs:17-44` declares but cannot receive the I/O failure.
- Refutation attempted: ran the adjacent `report` command against the same missing root; it rejects the root and exits nonzero, so absence is not a necessary or system-wide empty-run convention. Searched current regrade tests; none exercises an absent or unreadable trials root.
- Suggested closure: make trial enumeration fallible, propagate an exact run-root I/O/shape error through the CLI, return nonzero, and add discriminating missing-root and unreadable-root tests.

### P18-AUD-002: Rejected trial-identity reuse mutates the existing trial

- Axis: invariants
- Severity: Major
- Conformance effect: blocks
- Requirement IDs: P18-MIG-001, P18-EXP-005
- Claim: `run_trial` writes into an existing trial before checking its durable intent, so an identity-reuse rejection silently replaces `bench.toml` and may create additional directories.
- Evidence: `crates/opi-eval/src/runner/experiment.rs:1085-1138` performs directory creation and the configuration write before the intent check; `crates/opi-eval/tests/pairing_and_integrity.rs:123-144` checks only exit code and manifest bytes.
- Refutation attempted: reproduced a clean successful run, replaced `trial-opi-1/bench.toml` with `sentinel-opi`, and reran the identical valid request. The request correctly exited 2, but the sentinel was replaced with the fixture config; the sealed manifest remaining unchanged does not refute mutation of the existing trial root.
- Suggested closure: enforce the existing-intent/identity reservation check before any trial-root creation or write, and extend the reuse test to compare the complete pre-existing trial tree (or at minimum every mutable config/evidence path) byte-for-byte.
